# 校园二手（川大版）· 微信小程序测试版

校园全品类二手闲置交易平台 —— 依据《功能需求文档 V2.3》，微信小程序用户端 + 云开发后端。

## 技术选型

- **前端**：微信小程序原生（WXML / WXSS / JS）
- **后端**：微信云开发（云数据库、云存储、云函数、登录鉴权）
- **账号**：个人主体小程序（测试版）；正式上线二手交易类目需企业主体

## 川大标准色（红檐青砖）

| 颜色 | 值 | 用途 |
|---|---|---|
| 锦绣红 | `#B4100A` | 主色：导航、按钮、tab 选中 |
| 锦绣红·深 | `#8E0D08` | 按压态 |
| 中国红 | `#E60000` | 价格、竞价/售出强调 |
| 优雅灰 | `#87A1A1` | 辅助色 |

> HEX 为按官方 CMYK 换算值（锦绣红 C12 M92 Y95 K20 / 优雅灰 C47 M37 Y37 K0），非官方公布 HEX，如有 VI 手册以手册为准。

## 如何运行

1. 安装「微信开发者工具」。
2. 用你自己的小程序 AppID 导入本项目（或先填 `touristappid` 游客模式预览）。
3. 开通云开发，将环境 ID 填入 `app.js` 的 `wx.cloud.init({ env: '...' })`。
4. 编译即可看到首页效果。
