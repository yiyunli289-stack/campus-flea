# 小程序治理 V2.4 发布与验收

## 本地构建

使用 Node.js 20.19 或以上。在项目根目录运行：

```powershell
npm ci
npm test
npm run check
npm run build
```

`admin-web/dist` 是后台前端产物。发布云函数时使用 `cloudfunctions` 下入口、配置、依赖清单及构建生成的 `lib`。阿里云上的后台和微信小程序必须指向同一目标 CloudBase 环境。

## 独立环境联测

1. 用测试环境 ID 替换测试副本小程序初始化配置中的环境 ID。后台的 `TCB_ENV` 也设置为该 ID。使用对应环境的凭证配置后台，运行 `npm run bootstrap:cloud` 初始化业务设置与独立管理员。按照数据库默认配置清单创建集合及索引。
2. 构建函数后，部署 `login`、`goods`、`offer`、`chat`、`report`、`governance`、`config`、`ocr`、`governance-worker` 和 `safety-callback`。选择 Node.js 20.19。为每个业务函数设置相同的 `AUDIT_SECRET`。已有审计链的环境必须沿用其审计密钥。独立运行的 Web 后台使用 Node 管理 API。选用云端 HTTP 版后台时才部署 `admin`。
3. 根据函数配置设置微信安全检测接口权限，启用治理任务的分钟触发器。定时器必须使用可信的平台来源，部署后查看执行日志和已完成任务。微信审核回调由 `safety-callback` 接收，填写回调 Token、AES 密钥和实际 AppID，设置专用路由。
4. 按 [权限配置](security-rules.md) 在控制台分别应用 [规则模板](access-rules.json) 的数据库和存储子对象，核对 [索引清单](database-indexes.json)。把返回的 COS 主机加入上传合法域名。客户端通过云函数申请绑定路径的上传表单、登记和查询。
5. 卖家和买家均用真实微信测试账号登录。按下表验证，生产切换前记录通过结果。

| 场景 | 预期 |
|---|---|
| 发布即展示 | 上传登记后发布。另一账号立即能在首页和搜索找到商品，也能进入详情和报价。 |
| 后验审核失败与恢复 | 使用测试环境的审核模拟或管理员复核。审核暂不可用时保持在售。判违规后，搜索与交易动作即时关闭，旧链接仅显示提示。已获临时图片链接按有效期失效。 |
| 封禁和限权 | 两个账号保持会话，后台封禁或分项限权。下一次业务请求拒绝受限动作，安全中心显示原因，未受限功能和到期恢复符合 V2.4。 |
| 买家封禁与恢复 | 锁定后封禁买家。卖家商品变普通下架，双方不能继续交易，联系方式不再返回。卖家重上可接受新报价，旧报价不能恢复。 |
| 任务与历史 | 检查双方通知、只读历史、审核回调、任务失败重试、并发解封和恢复。对待审核、在售、违规、售出各保留一条测试数据。 |
| 微信上传与规则 | 新版用签名表单上传并登记。小程序身份不能直接写集合及云存储。封禁后不能新领上传表单或登记。验证 JPEG 与 PNG、旧商品编辑及受控文件读写。 |
| 账号注销 | 使用专门测试账号二次确认注销。公开资料和联系方式清除，退出交易；同一微信身份再次进入仍显示已注销。 |

## 用户验收后的生产切换

1. 确认环境 ID、微信 AppID、现有审计密钥、备份恢复点和当前云函数版本。导出集合数据及权限配置。准备维护窗口，以免迁移期间旧函数继续写入。
2. 以目标环境的本地服务端配置运行 `npm run migrate` 查看分集合计数。确认预览和备份后运行 `npm run migrate -- --apply`。迁移按批写入，可重复执行，保留已有审核结论和治理处置。已有在售且待补审的商品继续显示。
3. 先切换业务云函数和治理任务，再关闭客户端直接读写数据库与存储。用测试账号检查商品详情、后验审核、临时图片、后台封号、联系方式和任务日志。随后发布新版小程序并更新阿里云后台。当客户端仍采用旧的直传图片流程时，需要更新小程序版本才能发布含图商品。
4. 发布后查看审核及治理任务积压、失败任务和小程序错误率。遇到故障时优先切换到已验收且保留云端鉴权的函数版本，保持数据库和存储的客户端拒绝规则。没有该版本时，暂停受影响交易写入并修复。保留处置、审计及已注销标记。

## 本地验证记录

本地 42 项自动化测试通过，JavaScript 和 JSON 检查通过，后台编译与 11 个云函数打包完成。浏览器冒烟覆盖后台登录、审核、下架、角色权限、配置发布、书单校验和统计页面。真机上传域名、平台定时触发、微信安全检测回调和两账号联测待独立云环境验证。
