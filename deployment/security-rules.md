# 云端访问权限配置

应用角色与腾讯云账号权限是两套体系。以下配置是部署要求，源码中没有自动修改你的云端权限。

## 数据库

所有业务集合及新增治理集合均设置为仅管理端可读写（自定义规则 `read: false, write: false`）。普通用户通过业务云函数访问；Web 管理员通过管理 API 访问。不要把数据库管理员密钥发给浏览器，也不要给业务管理员腾讯云数据库控制台权限。

`auditLogs`、`auditArchives`、`adminUsers`、`adminSessions`、`systemLocks` 尤其不能开放客户端读写。应用不提供审计更新或删除接口。三年内不能对审计集合启用TTL清理。

## 云存储

上传目录为 `quarantine/<用户哈希>/<随机凭证>.jpg`。客户端只允许上传者读写自己的文件，禁止公开读和覆盖别人的文件。上传大小限制为10MB，类型限制为JPEG/PNG。具体规则语法以目标环境控制台支持的存储权限规则为准，至少选择“仅创建者可读写”。

业务图片对其他用户的展示由云函数在校验对象可见性之后签发临时URL；待审核图片只对上传者和授权审核员开放。临时URL属于持有者可访问链接，应使用短期有效期，不要记录在公开日志或静态页面中。已签发链接在到期前可能仍可使用，违规下架不能保证撤销已下载文件。

## 云函数与 HTTP 路由

- 小程序可调用 `login/goods/offer/chat/report/governance/config/ocr`，这些函数均有业务鉴权；公共配置和商品浏览允许未补全资料的访问。
- `admin` 仅通过 `/api/admin` 及其子路径提供HTTP服务，使用管理会话Cookie、权限码、CSRF和Origin校验。不要额外公开无鉴权的数据库代理。
- `safety-callback` 仅配置微信服务器审核消息回调路由，启用Token及AES加密配置；代码验证签名、时间和AppID。
- `governance-worker` 禁止客户端SDK调用、禁止配置公网HTTP路径。它只能由平台定时器调用，代码额外检查 `TCB_SOURCE=timer` 和Timer事件。若目标环境实际提供的可信来源值不同，先验证平台上下文再调整，不能仅信任客户端传入的 `Type` 字段。
- 其他管理服务和归档凭证按职责授权；后台角色不等于云函数的执行身份。

## 审计归档

归档账号仅授予指定桶的新增/读取权限，不授予删除、缩短保留期或修改桶策略权限。桶的保留策略至少覆盖三年；如需防止云资源管理员提前删除，使用存储级对象锁定并核实开通条件。保留期配置可能不可逆，启用前核对桶和期限。

数据库中的HMAC链用于完整性校验，不等于存储级不可删除。三年实际保留还依赖云端存储配置、定时归档、备份及持续可用的环境。
